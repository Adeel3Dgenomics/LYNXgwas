Add a project manually
  1. Copy projects/config.properties.template to projects/your_project_id/config.properties
  2. Edit the config file — set paths to your GWAS file, loci file, GFF3, and reference panel
  3. Map your GWAS column names (col.chr, col.pos, col.pvalue, col.ea, col.nea)
  4. Run run.bat — it will detect the new project and process it automatically
