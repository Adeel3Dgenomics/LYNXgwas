LYNXgwas — architecture & statistical pipeline

From raw GWAS summary statistics to cross-disease gene evidence

Every stage below corresponds to a real class in the codebase (shown in monospace) — this is not an idealized diagram, it traces the actual data flow through src/. Stages colored gold are new in this phase; a status tag on each statistical method notes whether it has been run end-to-end in this environment or only unit-tested (see DECISIONS_PHASE2.md for the exact, honest scope of each).
